## 2. 배포 순서 (1차, 새로 설치) — 초안, 4.5단계에서 승인 후 실행

> 🔒 = 승인 필요(`rules/server.md`). 비밀값(토큰 등)은 화면에 띄우지 않는다. `$REPO` = 서버 저장소 폴더.

```bash
# 0) 확인(읽기만): 실행 중인 서버가 없는지, 배포할 커밋
pgrep -a HomeAssistantCore; ss -ltn | grep -E ':(8000|8080) '
git -C $REPO log --oneline -1

# 1) 기존 운영 파일 보관(지우지 않고 이름만 바꿈) 🔒
mv $REPO/db/home_assistant.db $REPO/db/home_assistant.db.old-v0-$(date -u +%Y%m%dT%H%M%SZ)
mv $REPO/config/registered_devices.txt $REPO/config/registered_devices.txt.old-$(date -u +%Y%m%dT%H%M%SZ)

# 2) 폴더 권한: 소유자만 🔒
chmod 700 $REPO/config $REPO/db

# 3) 토큰 새로 만들기(값을 출력하지 않음, 600) 🔒 — 앱에는 서버에서 직접 옮겨 넣는다
( umask 077; openssl rand -hex 32 > $REPO/config/api_token )
stat -c '%a %s' $REPO/config/api_token      # 600, 65(64자+개행)

# 4) chip-tool 저장소: 새로 시작(기존 페어링 정보 버림 — 기기는 공장 초기화 후 재등록) 🔒
#    지우기 전에 목록 확인: ls -la /tmp/chip_tool*
mkdir -p ~/chip-tool-old && mv /tmp/chip_tool_* ~/chip-tool-old/ && chmod -R go-rwx ~/chip-tool-old
#    (새로 시작하지 않을 때는 대신: chmod 600 /tmp/chip_tool_*)

# 5) 운영 빌드(빌드 유형 비움, 구성 1회)
cmake -S $REPO -B $REPO/build -DHAC_BUILD_TESTS=OFF -DCMAKE_BUILD_TYPE= && cmake --build $REPO/build -j"$(nproc)"

# 6) 서버 시작 🔒 — build/에서 실행(상대 경로). 포트를 못 열면 종료 코드 1로 바로 끝난다
cd $REPO/build && ./HomeAssistantCore
```

배포 직후 확인:
- 새 DB가 생겼고 v1인지: `sqlite3 -readonly $REPO/db/home_assistant.db "PRAGMA user_version;"` → `1`(새 DB라 `.bak-v0`는 생기지 않음), 권한 `stat -c '%a' $REPO/db/home_assistant.db` → `600`(umask 077).
- 앱에서 기기 재등록(Matter: 공장 초기화 후 QR, TCP: BLE 등록) → 목록·제어 1회.
- **SEC-1차-13**: 커미셔닝이나 전력 조회로 chip-tool이 도는 동안 `ls -l /proc/$(pgrep -n chip-tool)/fd` → 0·1·2(파이프·`/dev/null`) 외에 `socket:`이 없어야 한다(서버의 8000·8080 소켓이 새지 않음).
- `/tmp/chip_tool_*` 새 파일 권한이 `600`인지: `stat -c '%a %n' /tmp/chip_tool_*`.
