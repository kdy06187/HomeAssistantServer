## 확정된 기획 결정 (2026-11-16)
- 방향: 핵심 계층 재설계(DeviceManager, 드라이버 인터페이스까지)
- 환경: 지금 집 LAN 1인, 나중에 외부 접속 예정 → A-05·N-07 처리, 인증 구조는 설계에 반영
- 범위: P1 전부(A+B+C+D), 기능 A~D 전부. 새 기기 종류, A-04, A-06, A-08은 범위 밖
- 호환: REST는 변경 가능(앱 수정, 변경 목록 문서화), TCP JSON은 100% 유지
- 하드웨어 모두 보유, 기한 없음
- 완료 기준: 단위 테스트 + 가짜 드라이버 통합 테스트 + 사용자 실행 실기 절차서. 테스트 프레임워크 도입은 미승인
