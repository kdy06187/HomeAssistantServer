## 4. 남은 위험·확인
- **V8 조용한 회귀**(12b-5): 상속만 지우면 Matter 플러그의 PC 종료 순서가 사라짐 → 회귀 시험을 먼저 쓰고 지움.
- 수락 스레드 정지 시간: 생존 확인 1초 + MAC 재시도 0.3초 중이면 `stop`이 최대 약 1.3초 늦음(5초 종료 상한 안).
- MAC 위조로 에이전트 밀어내기·스위치 칸 소진은 LAN 무인증 범위로 수용(SEC2-10·12, 결정 31).
- 등록 대기 30초 + 동기 E3 → TCP 등록 중 SIGTERM 종료 최대 약 36초(13번 취소 플래그로 해소). 실기 절차서에 "등록 중 서버 끄지 않기".
- SimpleBLE 예외·대기 30초·`/proc/net/arp` 실제 값·에이전트 재접속은 자동 시험 밖 → 6절 실기.
- TSan 빌드는 `-j3` 이하(인수인계).
- (12b-8 보안 재점검 추가) 한 MAC으로 계속 재접속하면 접속마다 생존 확인 1초 → 수락 스레드가 거의 계속 막혀 다른 기기 접속이 늦어질 수 있음(LAN 무인증 DoS, 수용). 후속 후보: 같은 IP·MAC 재접속 최소 간격, 기기 문자열 로그 정제. `reviews/security-12b-2026-11-23.md`.
